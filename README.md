# Java Hospital Management System

A Java-based Hospital Management System built using Object-Oriented Programming concepts.

## Features

- Patient management
- Doctor and staff management
- Appointment scheduling
- Medical records
- Treatment plans
- Prescription management
- Billing records
- Lab orders and diagnostic results
- Department management
- Role-based users
- Audit tracking
- Custom exception handling

## Technologies Used

- Java
- Object-Oriented Programming

## OOP Concepts Used

- Classes and Objects
- Encapsulation
- Inheritance
- Polymorphism
- Interfaces
- Exception Handling
- Collections

## Main Components

The project includes classes for:

- Patients
- Doctors
- Nurses
- Administrators
- Pharmacists
- Appointments
- Billing
- Medical Records
- Prescriptions
- Lab Orders
- Treatment Plans
- Departments

## What I Learned

This project helped me understand how Object-Oriented Programming can be used to build a larger real-world system.

I practiced working with multiple classes, inheritance, interfaces, custom exceptions, data management, and relationships between different objects.
